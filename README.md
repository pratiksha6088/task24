# Task 24 - Hello World (ReactJS)

## Description
This project is a simple ReactJS application that displays "Hello World!" in the browser.

## Technologies Used
- ReactJS
- JavaScript
- HTML
- CSS

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run:
   `npm install`
4. Then run:
   `npm start`
5. Open the localhost link in the browser.

## Output
The browser displays:

Hello World!
